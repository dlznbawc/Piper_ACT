# charge_align：充电口对准

手腕相机看到充电座，机械臂自己运动到**充电座正前方的对准位姿**并停住（不含插入）。

纯端到端：手腕 DaBai 图像 + 6 维关节角 → ACT → 6 维目标关节角，25Hz。"识别"隐含在策略里，没有单独的检测模块。

| 文件 | 作用 |
|------|------|
| `task.py` | `TaskSpec`：任务描述、不带夹爪、提示文字、终点停留 2 s、停稳判定 1 s |
| `record.py` | 采集示范 → `datasets/charge_align/`（流程在 `piper_act/record.py`） |
| `deploy.py` | 真机运行训练好的策略（流程在 `piper_act/deploy.py`） |
| `start_pose.json` | 起始位姿（第一次运行 record.py 时拖拽设定；采集和部署共用） |

以下命令都在仓库根目录运行，环境见[根目录 README](../../README.md)。

## 1. 采集

```bash
python3 tasks/charge_align/record.py
```

流程（脚本里有逐步提示）：拖拽示教（不录画面）→ 机械臂倒放回起始位姿 → 自己按示教轨迹回放并录制 → 终点原地再录 2 秒（让策略学会停）→ s 保存 / r 重来 / q 退出。再运行就接着录。

采集要点：
- **起始位姿**：手腕相机要能看到充电座可能出现的整个区域。之后所有示范和部署都从这里出发，定下来就别再改。
- **对准位姿的定义要一致**：比如"插头轴线对准座子轴线、离座面 3 cm"，每条都按同一个标准停，否则策略学到的终点会发散。
- **覆盖**：充电座的位置、朝向要分散，覆盖部署时会出现的范围；范围外的位置策略基本不会泛化。先录 50 条左右，看部署效果再补。
- 光照、背景也尽量和部署时一致，或者有意识地变化。

## 2. 训练

```bash
scripts/train.sh datasets/charge_align
```

## 3. 真机运行

```bash
python3 tasks/charge_align/deploy.py --policy outputs/train/act_charge_align/checkpoints/last/pretrained_model
```

每轮：放好充电座 → 回车开跑 → 动作停稳（1 秒内指令变化 < 0.005 rad）或 30 秒超时即停 → 回车沿原路退回起始位姿。Ctrl+C 随时停在原地。

| 参数 | 默认 | 说明 |
|------|------|------|
| `--max-step` | 0.03 | 每帧每关节最大变化（rad），限速保护。首次运行建议调小 |
| `--speed` | 50 | move_j 速度 %，与采集时 `--speed` 一致 |
| `--n-action-steps` | 20 | 每 20 帧（0.8 s）重新看图预测一次动作块；越小越闭环 |
| `--max-seconds` | 30 | 单轮超时 |

CPU 推理一次约 0.14～0.23 s（只在换动作块时发生），能跑但每 0.8 s 会顿一下。
