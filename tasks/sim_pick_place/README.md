# sim_pick_place：仿真抓放（iPhone 遥操作）

MuJoCo 里的 PiPER X（官方模型）抓起红色方块（位置随机），放到蓝色区域。不需要真机，用 iPhone 遥操作采集示范。

数据和真机 [pick_place](../pick_place/README.md) 同格式：25Hz，手腕相机 640×480 + 7 维状态 + 7 维动作（6 关节 + 夹爪开度 m）。

| 文件 | 作用 |
|------|------|
| `task.py` | 任务描述、数据集路径 |
| `record.py` | iPhone 遥操作采集 → `datasets/sim_pick_place/` |

仿真场景在 `src/piper_act/sim/env.py`，手机遥操作在 `src/piper_act/sim/phone.py`，机械臂模型在 `assets/piper_x/`。

## 准备 iPhone

1. App Store 装 **HEBI Mobile I/O**
2. App 设置里 **Family = `HEBI`、Name = `mobileIO`**（LeRobot 按这两个名字找手机）
3. 手机和电脑连**同一个 WiFi**（局域网 UDP 广播发现设备；公司网络隔离了设备之间的通信就连不上，可以用手机热点）

## 采集

```bash
python3 tasks/sim_pick_place/record.py
```

1. 启动后先**标定**：手机平放、屏幕朝上，**点一下** B1（「跟随 开/关」），看到"标定完成"后按提示再点一下关掉（标定只确定"哪边是上"）
2. **方向**：每次点 B1 开始跟随的那一刻，手机顶边指向哪里，哪里就是机械臂的前方（+x）。窗口默认从机械臂后方看，所以人正对电脑屏幕、顶边指向屏幕再点 B1，之后手机往屏幕方向推 = 屏幕里机械臂往前，往左 = 往左。跟随过程中转动手机不影响方向，只看平移
3. 弹出 MuJoCo 窗口：主画面是场景，右上角是手腕相机画面，左上角是状态
4. 每条示范：

| 操作 | 作用 |
|------|------|
| 点一下 **B1**，再移动手机 | 机械臂开始跟随（相对移动，手机移 10 cm = 夹爪移 10 cm，`--scale` 可调）。再点一下 = 暂停，可以挪手再点。**第一次开始跟随才开始录制**。手机背面摄像头别挡住，对着有纹理的桌面/地面（手机靠它定位） |
| **A3** 滑块 | 往上推张开、往下拉闭合，松手回中 = 停住 |
| **B2** | 保存本条（窗口显示 `SUCCESS` 才能保存：方块在蓝色区域内、落在桌上、夹爪已松开） |
| **B3** | 丢弃，换一个方块位置重来 |
| **B8** / 关窗口 | 退出（已保存的不受影响） |

采集要点：
- 动作连贯一点，别在空中长时间停顿（策略会学到"停住"）。放好、松开、抬起后尽快按 B2。
- 夹爪始终竖直朝下，不跟随手机转动。
- 窗口显示 `Target UNREACHABLE`：手机带着目标点跑到机械臂够不到的地方了，往回收一点。
- 先录 50 条左右。同一个数据集再运行就接着录，方块位置的随机种子也接着往下排。
