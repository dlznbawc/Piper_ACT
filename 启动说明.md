# 启动说明

每段整段复制到新终端执行。

## 仿真抓放（iPhone 遥操作）

采集：

```bash
cd /home/admin123/Development/Piper_ACT
conda activate piper_act
export PYTHONNOUSERSITE=1
python3 tasks/sim_pick_place/record.py --scale 0.5
```

`--scale` 是灵敏度：手机移 10 cm → 机械臂移 10×scale cm。还嫌太灵敏就改小（如 0.3），太迟钝就改大。

训练：

```bash
cd /home/admin123/Development/Piper_ACT
conda activate piper_act
export PYTHONNOUSERSITE=1
scripts/train.sh datasets/sim_pick_place
```

## 真机

开机后先启动一次 CAN（会要密码）：

```bash
sudo ip link set can0 up type can bitrate 1000000
```
